# Kaggle House Prices Prediction (Linear Regression Baseline)

This repository contains my submission for the Kaggle **House Prices - Advanced Regression Techniques** competition. 

I built this project directly using the foundational machine learning concepts I learned up to **Week 2 of the Coursera Machine Learning Specialization**.

## 🚀 Key Machine Learning Concepts Applied
* **Multi-variable Linear Regression:** Mapping multiple numerical features (e.g., Lot Area, Quality, Floor Square Footage) to predict a continuous target variable (`SalePrice`).
* **Feature Scaling (Z-score Normalization):** Rescaling feature values to help Gradient Descent converge much faster and more efficiently.
* **Baseline Modeling:** Utilizing `scikit-learn`'s LinearRegression to fit parameters (w and b) and evaluate predictions.

## 📁 Dataset
The data is sourced directly from the [Kaggle House Prices Competition](https://kaggle.com). 
*(Note: Per Kaggle's terms of service, the raw data files are not included in this repository).*

## 🛠️ Tech Stack
* Python
* NumPy & Pandas (Data Manipulation)
* Scikit-Learn (Modeling)
